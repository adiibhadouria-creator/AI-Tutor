# AI-Tutor
ProfAI v2 - An adaptive AI tutor platform built on Cloudflare Workers.  Features include: - Diagnostic assessments and Socratic tutoring - Auto-generated Mermaid diagrams - Multi-chat history (ChatGPT-style) - PDF report generation &amp; export - Secure email/password authentication - Real-time streaming responses  Built with Next.js/React (via vinext)
